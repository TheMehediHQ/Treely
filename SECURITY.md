# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Trelly, please report it responsibly.

**Please do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email us at [INSERT EMAIL HERE] with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt of your report within 3 business days and provide a more detailed response within 7 business days indicating the next steps.

| Version | Supported          |

| 1.x     | :white_check_mark: |

## Security Updates

We will release security patches as needed. Please watch this repository for releases and security advisories.
